# Placeholder photography

Every photograph in `public/images/` is a **temporary placeholder** chosen to match a natural
freshwater spring resort: spring-fed pools, rock ledges, clear freshwater streams, forest and
wooden cottages. No beach, ocean, coastal, boat or hotel-pool imagery is used.

Replace all of these with the resort owner's own photographs before launch. When you do, keep the
same file names and aspect ratios (see the table) so the layouts continue to work, and delete this
file plus the "Photography credits" block in `src/components/Footer.tsx`
(`imageCredits` in `src/data/resort.ts`).
